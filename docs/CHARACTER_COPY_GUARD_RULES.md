# 人物不照搬检查规则

> 版本：0.1.0
> 状态：草案（尚未实现）
> 关联任务：T068

---

## 1. 功能定位

Character Copy Guard（人物不照搬检查器）专门检查 AI 生成的 Story Bible 或小说章节中的人物是否直接搬运或变相复刻了参考小说中的角色。

**核心原则：允许借鉴抽象人物类型，禁止复制任何具体人物特征。**

---

## 2. 检查范围

Character Copy Guard 从以下维度逐项检查：

| 维度 | 说明 |
|---|---|
| 角色名 | 名称的精确匹配和变体检测 |
| 身份设定 | 职业、年龄、社会地位、家庭背景的组合 |
| 性格组合 | 性格特质、行为模式、价值观的组合 |
| 外貌特征 | 标志性外貌特征（如有） |
| 人物关系网络 | 人物之间的关联结构 |
| 角色弧光 | 角色的成长轨迹和转变模式 |
| 能力/技能设定 | 如果存在特殊能力体系 |

---

## 3. 角色名检查

### 3.1 检查方法

| 层级 | 检查方式 | 示例 |
|---|---|---|
| 精确匹配 | 检查是否直接出现 `name_map.json` 中的原始角色名 | "张三" → "张三" |
| 同音替换 | 声母韵母相同、声调不同的汉字替换 | "张三" → "章三" |
| 形近替换 | 偏旁部首或字形相似的字替换 | "张三" → "张彡" |
| 拆字替换 | 将单个字拆分为多个字 | "张三" → "张一一" |
| 翻译/拼音替换 | 中文名转拼音或英文转中文 | "Harry" → "哈瑞" |
| 颠倒/重组 | 名字的倒序或拆散重组 | "张三丰" → "丰三张" |
| 别名/外号 | 参考小说中角色的别名或外号 | "大耳贼" → "大耳贼" |

### 3.2 判定规则

| 条件 | 结果 | 严重程度 |
|---|---|---|
| 精确匹配原始角色名 | FAIL | critical |
| 同音/形近/拆字/拼音变体 | FAIL | critical |
| 出现原始角色的别名或外号 | FAIL | critical |
| 名称无相似性 | PASS | - |

---

## 4. 身份设定检查

### 4.1 检查方法

将角色的身份设定分解为多个维度，与参考小说角色进行多维度对比。

| 维度 | 权重 | 说明 |
|---|---|---|
| 职业类型 | 25% | 职业的类别和行业 |
| 年龄区间 | 10% | 年龄范围（少年/青年/中年/老年） |
| 社会地位 | 15% | 社会阶层、经济状况 |
| 家庭背景 | 25% | 家庭结构、成长经历 |
| 特殊身份 | 25% | 隐藏身份、特殊使命（如有） |

### 4.2 判定规则

| 条件 | 结果 | 严重程度 |
|---|---|---|
| 5 个维度中有 4+ 个与同一参考角色一致 | FAIL | high |
| 5 个维度中有 3 个与同一参考角色一致 | WARN | medium |
| 5 个维度中有 2 个或以下一致 | PASS | - |

---

## 5. 性格组合检查

### 5.1 检查方法

将性格分解为可量化的特质标签，与参考角色对比。

**特质标签示例：**
`内向/外向`、`理性/感性`、`主动/被动`、`乐观/悲观`、`果断/犹豫`、`自信/自卑`、`宽容/记仇`、`独立/依赖`

### 5.2 判定规则

| 条件 | 结果 | 严重程度 |
|---|---|---|
| 核心性格标签（前 5 个主要标签）完全一致 | FAIL | high |
| 核心性格标签 3-4 个一致 | WARN | medium |
| 核心性格标签 2 个或以下一致 | PASS | - |

**注意：** 性格标签本身是通用的（"内向""理性"等），只有在多个标签组合与同一参考角色高度一致时才触发警告。

---

## 6. 外貌特征检查

### 6.1 检查方法

对参考角色具有的**标志性外貌特征**进行检查。普通的外貌描述（如"黑色头发""中等身材"）不作为检查对象。

| 特征类型 | 示例 | 是否标志性 |
|---|---|---|
| 疤痕/胎记 | "额头有一道闪电形疤痕" | 是 |
| 特殊瞳色/发色 | "天生的银白色头发" | 是 |
| 体型特征 | "异常高大"、"极其瘦弱" | 视具体情况 |
| 普通描述 | "黑色短发"、"身高 175cm" | 否 |

### 6.2 判定规则

| 条件 | 结果 | 严重程度 |
|---|---|---|
| 原创角色的标志性外貌特征与某参考角色一致 | FAIL | high |
| 非标志性外貌特征相似 | PASS | - |

---

## 7. 关系网络检查

### 7.1 检查方法

将人物关系抽象为图结构：节点 = 角色类型，边 = 关系类型。

```
参考小说关系图：              待检查关系图：
  [主角]──恋人──[女配]         [主角A]──恋人──[角色B]
    │                │           │                │
   师徒              兄妹        师徒              兄妹
    │                │           │                │
  [导师]            [女配弟]    [角色C]           [角色D]
```

### 7.2 判定规则

| 条件 | 结果 | 严重程度 |
|---|---|---|
| 关系图完全同构（节点数相同 + 边类型匹配度 > 90%） | FAIL | critical |
| 关系图高度相似（节点数相同 + 边类型匹配度 70-90%） | FAIL | high |
| 关系图局部相似（核心三角关系一致） | WARN | medium |
| 关系图结构明显不同 | PASS | - |

---

## 8. 角色弧光检查

### 8.1 检查方法

将角色弧光抽象为阶段序列进行对比。

**弧光阶段类型：**
`起始状态 → 触发事件 → 抗拒 → 接受 → 成长 → 代价 → 新平衡`

### 8.2 判定规则

| 条件 | 结果 | 严重程度 |
|---|---|---|
| 弧光阶段序列完全一致 + 触发事件类型相同 | FAIL | high |
| 弧光阶段序列一致但触发事件类型不同 | WARN | medium |
| 弧光类型相同（如都是"正向成长弧"）但阶段序列不同 | PASS | - |

**注意：** 弧光类型（如"正向成长弧"、"悲剧式堕落弧"）是通用抽象概念，本身不构成违规。只有当弧光的阶段序列和触发事件类型与参考角色高度一致时才触发警告。

---

## 9. 允许借鉴的抽象人物类型

| 允许借鉴 | 示例 | 原因 |
|---|---|---|
| 人物原型/角色定位 | "反抗型成长主角"、"导师型配角"、"理性克制型恋人" | 通用类型，非具体人物 |
| 通用的角色功能 | "提供喜剧缓解的角色"、"作为道德参照的角色" | 功能而非特征 |
| 成长弧类型 | "正向成长弧"、"堕落弧"、"救赎弧" | 抽象模式 |
| 关系模式 | "若即若离的恋人"、"爱而不言的父子" | 抽象关系模式 |
| 冲突角色类型 | "制度性阻碍者"、"内心矛盾者" | 抽象冲突定位 |

---

## 10. 禁止搬运的具体人物特征

| 禁止搬运 | 示例 | 原因 |
|---|---|---|
| 具体角色名及变体 | "张三" → "章三" | 直接侵权风险 |
| 具体身份组合 | "32 岁广告公司创意总监 + 单身 + 父亲是退伍军人" | 具体人物画像 |
| 标志性外貌 | "额头闪电形疤痕" | 独特标识 |
| 完整性格标签组合 | 5 个标签完全一致的组合 | 人格复制 |
| 人物关系网络 | 节点数相同 + 边类型匹配 | 关系网络搬运 |
| 角色弧光阶段序列 | "起-抗-接-成-代价-平衡" 完全对应 | 成长轨迹复制 |
| 角色的口头禅或标志性动作 | 参考小说中角色独有的表达方式 | 人物特征盗用 |

---

## 11. 风险等级汇总

| 检查维度 | 最高严重程度 | 判定关键 |
|---|---|---|
| 角色名 | critical | 精确匹配或变体 |
| 身份设定 | high | 5 维度中有 4+ 一致 |
| 性格组合 | high | 核心标签完全一致 |
| 外貌特征 | high | 标志性特征一致 |
| 关系网络 | critical | 图结构完全同构 |
| 角色弧光 | high | 阶段序列 + 触发事件一致 |

---

## 12. 修改建议输出格式

当检查 FAIL 或 WARN 时，输出具体的修改建议：

```json
{
  "check_id": "CHAR-001",
  "character_name": "角色A",
  "reference_character": "参考作品A中的XX",
  "violation_type": "身份设定高度相似",
  "severity": "high",
  "detail": "原创角色'角色A'的5个身份维度中有4个与参考角色'XX'一致",
  "matched_dimensions": ["职业类型", "年龄区间", "社会地位", "家庭背景"],
  "suggestions": [
    "建议将'职业类型'从'广告创意总监'改为其他创意行业",
    "建议将'家庭背景'从'退伍军人父亲'改为其他背景",
    "建议至少修改2个维度的设定以降低相似度"
  ]
}
```
