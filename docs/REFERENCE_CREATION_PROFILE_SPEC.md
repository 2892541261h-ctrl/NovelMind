# Reference Creation Profile 字段规格草案

> 版本：0.1.0
> 状态：草案（尚未实现）
> 关联任务：T061

---

## 1. 功能定位

Reference Creation Profile（参考创作档案）是从参考小说中**抽象提取**出来的"参考方向档案"。它不是用户原创小说本身，也不是参考小说的可续写上下文。

**核心约束：**

| 允许 | 禁止 |
|---|---|
| 从参考小说中抽象类型规律、结构规律、风格规律、冲突规律 | 直接复制参考小说原文 |
| 辅助生成用户自己的原创 Story Bible | 用作续写参考小说的大纲或上下文 |
| 作为 Daily Writer 的参考方向输入（间接） | 作为 Daily Writer 的直接生成输入 |
| 记录"参考小说怎样组织冲突模式" | 记录"参考小说的具体情节每一步是什么" |
| 记录"第一人称冷峻文风" | 记录参考小说原文段落 |

---

## 2. 与 Story Bible 的关系

```
参考小说（只读）
    │
    ▼
Reference Creation Profile  ← 从参考小说抽象出的创作方向
    │                        （类型规律 / 结构规律 / 风格规律 / 冲突规律）
    ▼
Story Bible                 ← 用户自己的原创小说设定
    │                        （世界观 / 角色 / 地点 / 时间线 / 风格 / 剧情线）
    ▼
Daily Writer                ← 根据 Story Bible 写用户自己的小说
    │                        可参考 Reference Creation Profile，但不能直接复刻参考小说
    ▼
用户原创小说章节
```

**关键区别：**

| | Reference Creation Profile | Story Bible |
|---|---|---|
| 来源 | 从参考小说分析抽象 | 用户自己的创作设计 |
| 归属 | 参考方向（不直接产出文本） | 用户原创世界观 |
| 包含 | 抽象规律、模式、方向 | 具体角色名、地点名、事件、时间线 |
| 可写入 | 否（只读档案） | 是（可修改的设定文档） |
| 用于生成 | 辅助方向参考 | 直接写作上下文 |

| 7 | `relationship_patterns` | 关系模式 | `list[object]` | 否 |
| 8 | `conflict_patterns` | 冲突模式 | `list[object]` | 是 |
| 9 | `plot_progression_model` | 剧情推进模型 | `string` | 是 |
| 10 | `chapter_structure_pattern` | 章节结构规律 | `object` | 否 |

## 4. 字段详细说明

### 4.1 `reference_title`

| 属性 | 值 |
|---|---|
| **中文名** | 参考作品标题（匿名化） |
| **类型建议** | `string` |
| **是否必填** | 是 |
| **用途** | 用于标识该档案来源于哪部参考小说。在生成用户原创内容时，应使用匿名化代号（如"参考作品 A"），而非真实作品名，以防止后续流程无意识地搬运专有名词。 |

**示例：**

```json
"reference_title": "参考作品 A"
```

**禁止内容：**

- 真实知名小说名称（如《哈利·波特》《三体》《鬼灭之刃》）
- 真实作者姓名
- 真实出版社名称

---

### 4.2 `genre`

| 属性 | 值 |
|---|---|
| **中文名** | 类型/流派 |
| **类型建议** | `string` |
| **是否必填** | 是 |
| **用途** | 描述参考小说所属的类型和流派组合，帮助 Story Bible Generator 确定目标小说的类型定位。 |

**示例：**

```json
"genre": "都市现实 + 心理学 + 悬疑"
```

**禁止内容：**

- 不写"XX 小说的同人"
- 不写"XX 世界观下的衍生作"

---

### 4.3 `worldbuilding_pattern`

| 属性 | 值 |
|---|---|
| **中文名** | 世界观构建模式 |
| **类型建议** | `string` |
| **是否必填** | 是 |
| **用途** | 抽象描述参考小说如何构建世界观——是逐步揭示还是开篇铺陈？是硬规则还是软规则？世界观的"规则感"有多强？ |

**示例：**

```json
"worldbuilding_pattern": "逐步揭示型。开篇只展示与主角日常生活直接相关的一小部分世界规则，随剧情推进通过冲突和对话逐渐展开更宏观的世界设定，直到中期才让读者形成完整的世界认知。"
```

**禁止内容：**

- 不包含地名、组织名、专有术语
- 不包含"那个世界叫 XX 大陆"之类的具体设定

---

### 4.4 `setting_rules`

| 属性 | 值 |
|---|---|
| **中文名** | 设定规则 |
| **类型建议** | `list[string]` |
| **是否必填** | 否 |
| **用途** | 逐条列出从参考小说中抽象出的通用设定规则，每条为一个独立的规律性描述。 |

**示例：**

```json
"setting_rules": [
  "故事发生在与现实世界高度相似的都市环境中，无架空地名",
  "社会运行遵循现实逻辑：角色需要租房、通勤、处理家庭关系",
  "不存在超自然力量或魔法体系",
  "科技水平与当下现实一致"
]
```

**禁止内容：**

- 不包含具体地名
- 不包含具体数值（如"2034 年"、"第 7 区"）

---

### 4.5 `power_system_or_core_mechanism`

| 属性 | 值 |
|---|---|
| **中文名** | 力量体系/核心机制 |
| **类型建议** | `string` |
| **是否必填** | 否 |
| **用途** | 如果参考小说中存在特殊力量体系（如修仙、异能、游戏系统、科幻技术），抽象描述其运作机制。如果没有特殊体系，写"无特殊力量体系"。 |

**示例（有力量体系）：**

```json
"power_system_or_core_mechanism": "核心机制为一种通过特定仪式激发的人体潜能，消耗精神力作为代价。力量层级分为五个阶段，每阶段解锁不同能力范围。高级能力者稀少且受政府监管。"
```

**示例（无力量体系）：**

```json
"power_system_or_core_mechanism": "无特殊力量体系。角色能力差异来源于社会地位、职业技能和人际关系资源的差距。"
```

**禁止内容：**

- 不包含具体招式名、功法名、道具名
- 不包含能力数值

---

### 4.6 `character_archetypes`

| 属性 | 值 |
|---|---|
| **中文名** | 人物原型 |
| **类型建议** | `list[object]`，每个对象含 `role`、`archetype`、`core_motivation`、`arc_type` |
| **是否必填** | 是 |
| **用途** | 将参考小说中的角色抽象为人物原型，而不是罗列角色名。Story Bible Generator 可根据这些原型设计原创角色。 |

**示例：**

```json
"character_archetypes": [
  {
    "role": "主角",
    "archetype": "反抗型成长主角 —— 起始于被动接受环境的普通人，在关键事件后转为主动改变命运",
    "core_motivation": "寻求自我价值认同，同时承担家庭责任与个人理想的冲突",
    "arc_type": "正向成长弧 —— 从逃避到直面"
  },
  {
    "role": "主角的核心关系对象",
    "archetype": "理性克制型角色 —— 与主角形成感性与理性的对照",
    "core_motivation": "在事业成功与情感需求之间寻找平衡",
    "arc_type": "破冰型 —— 从壁垒高筑到逐渐放下防备"
  },
  {
    "role": "主要对抗者",
    "archetype": "制度性阻碍者 —— 代表系统压力而非个人恶意",
    "core_motivation": "维护现有秩序，视个人表达为不稳定因素",
    "arc_type": "无显著弧光 —— 作为恒定的外部压力存在"
  }
]
```

**禁止内容：**

- 不出现具体角色名
- 不出现"相当于《XX》的 YY 角色"
- 不把角色名替换为同义词后照搬（如"哈利·波特"→"哈瑞·波特"）

---

### 4.7 `relationship_patterns`

| 属性 | 值 |
|---|---|
| **中文名** | 关系模式 |
| **类型建议** | `list[object]`，每个对象含 `type`、`dynamic`、`tension_source` |
| **是否必填** | 否 |
| **用途** | 抽象描述参考小说中人物关系的模式和张力来源。 |

**示例：**

```json
"relationship_patterns": [
  {
    "type": "主角与核心关系对象",
    "dynamic": "若即若离 —— 两人互相吸引但因各自的性格和人生选择而不断错过",
    "tension_source": "双方对亲密关系持有矛盾的渴望与恐惧"
  },
  {
    "type": "主角与父辈",
    "dynamic": "爱而不言 —— 父亲以行动表达关心，但无法进行情感层面的沟通",
    "tension_source": "代际价值观差异与传统家庭期待"
  }
]
```

**禁止内容：**

- 不出现具体人物名
- 不出现具体的关系事件（如"第 10 章表白被拒"）

---

### 4.8 `conflict_patterns`

| 属性 | 值 |
|---|---|
| **中文名** | 冲突模式 |
| **类型建议** | `list[object]`，每个对象含 `type`、`nature`、`resolution_style` |
| **是否必填** | 是 |
| **用途** | 抽象描述参考小说中的冲突类型、冲突本质和解决方式。 |

**示例：**

```json
"conflict_patterns": [
  {
    "type": "人物 vs 自我",
    "nature": "主角在理想与现实之间的挣扎，本质是价值观冲突",
    "resolution_style": "渐进式 —— 不通过单一事件解决，而是在多个场景中反复博弈后逐渐偏移"
  },
  {
    "type": "人物 vs 社会期望",
    "nature": "家庭和社会对'正常人生轨迹'的期待与个人选择之间的矛盾",
    "resolution_style": "妥协与坚持交替 —— 在次要事务上让步，核心原则上不退让"
  },
  {
    "type": "人物 vs 人物",
    "nature": "价值观差异导致的理解错位，非善恶对抗",
    "resolution_style": "通过共同经历逐渐弥合，无胜负之分"
  }
]
```

**禁止内容：**

- 不出现"角色 A 与角色 B 在第 X 章因 Y 事件发生冲突"
- 不包含具体情节桥段

---

### 4.9 `plot_progression_model`

| 属性 | 值 |
|---|---|
| **中文名** | 剧情推进模型 |
| **类型建议** | `string` |
| **是否必填** | 是 |
| **用途** | 抽象描述参考小说的剧情如何推进——是按时间线性推进？多线并行？倒叙插叙？驱动力是事件驱动还是人物驱动？ |

**示例：**

```json
"plot_progression_model": "人物驱动 + 日常推进型。整体按时间线性推进，无明显倒叙或插叙。剧情节点不依赖外部事件，而是由人物的内在选择推动。章节之间的连接以人物状态变化为线索，而非以悬念或谜题为牵引。节奏缓慢，每隔约 8-10 章出现一次较大的人物关系变化作为阶段性推手。"
```

**禁止内容：**

- 不包含"开头—发展—高潮—结尾"的具体事件列表
- 不包含章节级剧情概要

---

### 4.10 `chapter_structure_pattern`

| 属性 | 值 |
|---|---|
| **中文名** | 章节结构规律 |
| **类型建议** | `object`，含 `avg_word_count`、`opening_style`、`closing_style`、`scene_count_range`、`pov_switching` |
| **是否必填** | 否 |
| **用途** | 抽象描述参考小说的单章结构规律。 |

**示例：**

```json
"chapter_structure_pattern": {
  "avg_word_count": "约 2500-3500 字/章",
  "opening_style": "通常以场景描写或人物内部状态开章，不使用对话或悬念开章",
  "closing_style": "以情感余韵收尾，不使用 hook 式断章",
  "scene_count_range": "1-3 个场景/章",
  "pov_switching": "单章内不切换视角"
}
```

**禁止内容：**

- 不描述具体章节内容
- 不包含"第 X 章以什么事件收尾"

---

### 4.11 `writing_style_profile`

| 属性 | 值 |
|---|---|
| **中文名** | 写作风格档案 |
| **类型建议** | `object`，含 `tone`、`narration_distance`、`dialogue_ratio`、`description_style`、`sentence_style` |
| **是否必填** | 是 |
| **用途** | 抽象描述参考小说的写作风格特征。 |

**示例：**

```json
"writing_style_profile": {
  "tone": "冷峻克制 —— 叙述者保持情感距离，不进行直白抒情",
  "narration_distance": "近距第三人称 —— 主要跟随主角的感知，但不进入内心独白",
  "dialogue_ratio": "约 30% 对话，70% 叙述与描写",
  "description_style": "以细节取胜，用环境映射人物情绪，不使用比喻堆砌",
  "sentence_style": "中短句为主，节奏干净，不使用长复合句"
}
```

**禁止内容：**

- 不引用原文句子
- 不出现"像 XX 作家的文风"

---

### 4.12 `pacing_profile`

| 属性 | 值 |
|---|---|
| **中文名** | 节奏档案 |
| **类型建议** | `object`，含 `overall`、`major_event_spacing`、`calm_interval_style` |
| **是否必填** | 否 |
| **用途** | 抽象描述参考小说的叙事节奏。 |

**示例：**

```json
"pacing_profile": {
  "overall": "慢热型 —— 前期以日常铺垫为主，中段逐渐加速，关键节点密集爆发后恢复日常",
  "major_event_spacing": "约每 8-10 章出现一次较大的人物关系或剧情转折",
  "calm_interval_style": "用小事件和人物互动填充高潮之间的平静期，避免让读者感到空洞"
}
```

**禁止内容：**

- 不包含具体事件的时间节点
- 不包含"第 X 章出现第一个高潮"

### 4.13 `emotional_tone`

| 属性 | 值 |
|---|---|
| **中文名** | 情感基调 |
| **类型建议** | `string` |
| **是否必填** | 否 |
| **用途** | 描述参考小说整体传递的情感底色和读者在阅读时的主要情感体验。 |

**示例：**

```json
"emotional_tone": "温暖与孤独交织 —— 主要情感底色为都市孤独感，但在人际关系细节中透出温暖。不煽情，不绝望，始终在灰色基调中保留微光。"
```

**禁止内容：**

- 不包含具体情感场景描述

---

### 4.14 `reader_hook_patterns`

| 属性 | 值 |
|---|---|
| **中文名** | 读者钩子模式 |
| **类型建议** | `list[string]` |
| **是否必填** | 否 |
| **用途** | 抽象描述参考小说吸引读者持续阅读的"钩子"模式。 |

**示例：**

```json
"reader_hook_patterns": [
  "人物共情型钩子 —— 读者因对主角内心世界的深刻共情而继续阅读，而非依赖情节悬念",
  "细节发现型钩子 —— 在场景描写中埋入微妙的人物细节，读者通过发现这些细节获得满足感",
  "关系期待型钩子 —— 主角与核心关系对象之间若即若离的状态让读者期待下一次互动"
]
```

**禁止内容：**

- 不描述具体情节转折
- 不包含"在第 X 章埋下一个伏笔"

---

### 4.15 `taboo_or_avoid_rules`

| 属性 | 值 |
|---|---|
| **中文名** | 禁忌/避免规则 |
| **类型建议** | `list[string]` |
| **是否必填** | 否 |
| **用途** | 列出从参考小说分析中提取的"应该避免"的内容方向和风格特征。帮助 Story Bible Generator 和 Daily Writer 知道不要写成什么样。 |

**示例：**

```json
"taboo_or_avoid_rules": [
  "避免使用超自然元素来解释关键剧情转折",
  "避免善恶二元对立的角色塑造",
  "避免使用大段内心独白推进剧情",
  "避免以'天降救星'的方式解决冲突"
]
```

**禁止内容：**

- 不写成参考小说的负面评价

---

### 4.16 `originality_rules`

| 属性 | 值 |
|---|---|
| **中文名** | 原创性规则 |
| **类型建议** | `list[object]`，每个对象含 `rule`、`severity`、`action_on_violation` |
| **是否必填** | 是 |
| **用途** | 定义在使用此档案生成原创内容时必须遵守的原创性规则。这些规则将被 Originality Checker 在生成流程中执行。 |

**示例：**

```json
"originality_rules": [
  {
    "rule": "禁止生成内容中出现参考小说的具体角色名",
    "severity": "critical",
    "action_on_violation": "阻止生成，要求重新输出"
  },
  {
    "rule": "禁止搬运参考小说中超过 15 个连续字词的原文段落",
    "severity": "critical",
    "action_on_violation": "阻止生成，要求重新输出"
  },
  {
    "rule": "禁止以只替换名称的方式复刻参考小说的人物关系网络",
    "severity": "high",
    "action_on_violation": "标记为高风险，转入人工确认"
  },
  {
    "rule": "禁止以只替换背景设定的方式复刻参考小说的完整剧情链条",
    "severity": "high",
    "action_on_violation": "标记为高风险，转入人工确认"
  },
  {
    "rule": "禁止生成会让读者合理地认为是在续写参考小说的内容",
    "severity": "medium",
    "action_on_violation": "标记警告，建议人工审查"
  }
]
```

**禁止内容：**

- 不能写成空洞的免责声明
- 必须可被自动化脚本校验（至少部分规则）

---

### 4.17 `target_novel_direction`

| 属性 | 值 |
|---|---|
| **中文名** | 目标小说方向 |
| **类型建议** | `string` |
| **是否必填** | 是 |
| **用途** | 描述基于此参考档案，目标原创小说的创作方向。这是"从参考小说学到了什么"到"我们要写什么原创小说"的桥梁。 |

**示例：**

```json
"target_novel_direction": "创作一部以当代中国二线城市为背景的都市现实主义长篇小说。主角是一位在传统期望与个人理想之间挣扎的年轻职业人。借鉴参考作品对人物内心世界的细腻刻画和对都市孤独感的把握，但世界观、人物关系网络和核心冲突均重新设计为原创内容。故事围绕'工作意义'、'代际理解'和'亲密关系恐惧'三者之间的张力展开。"
```

**禁止内容：**

- 不包含"类似 XX 小说但换成中国背景"
- 不写成参考小说的"改编说明"

## 5. 原创性规则

Reference Creation Profile 的生成和使用必须遵守以下原创性规则：

### 5.1 抽象层级要求

| 层级 | 说明 | 是否允许 |
|---|---|---|
| 具体原文 | 直接复制参考小说原文段落 | ❌ 禁止 |
| 具体情节 | "角色 A 在第 5 章做了 X 事件" | ❌ 禁止 |
| 具体名称 | 角色名、地名、组织名、专有术语 | ❌ 禁止 |
| 剧情链条 | "先发生 A → 然后 B → 然后 C"的完整序列 | ❌ 禁止 |
| 简单换皮 | 只改名称不改结构的复刻 | ❌ 禁止 |
| **类型规律** | "该类作品通常使用哪种冲突模式" | ✅ 允许 |
| **结构规律** | "章节通常如何组织" | ✅ 允许 |
| **风格规律** | "文风基调、叙事距离、句法特征" | ✅ 允许 |
| **冲突规律** | "典型冲突类型和解决方式" | ✅ 允许 |
| **人物原型** | "主角通常具有何种成长弧" | ✅ 允许 |

### 5.2 不可包含的内容

- 参考小说的完整或部分原文
- 参考小说角色的真实名称（包括外号、代号）
- 参考小说中独有的专有名词（包括地名、组织名、特殊物品名、招式名）
- 超过 2 句的连续场景描述
- 可识别的具体剧情桥段（如"主角在火车站发现自己是巫师"）
- 对参考小说可续写的暗示（如"请续写 XX 小说的第 N 章"）

### 5.3 允许的抽象方式

- 将"哈利·波特收到霍格沃茨录取通知书"抽象为"主角从一个平凡环境中被引入一个隐藏的特殊世界"
- 将"鸣人的影分身之术"抽象为"主角拥有一种可以制造替身的能力"
- 将"路飞的海贼团"抽象为"主角带领一个由不同特长的成员组成的小团队"

## 6. 后续系统使用方式

### 6.1 Story Bible Generator

读取 `target_novel_direction`、`genre`、`character_archetypes`、`conflict_patterns`、`worldbuilding_pattern` 生成用户原创 Story Bible。

- 输入：Reference Creation Profile
- 输出：StoryBible（用户原创设定）
- 不输入：参考小说原文

### 6.2 Daily Writer

读取 `writing_style_profile`、`pacing_profile`、`chapter_structure_pattern`、`reader_hook_patterns` 作为写作风格参考。

- 主要输入：用户自己的 Story Bible + 已有章节 + 本章目标
- 参考输入：Reference Creation Profile（间接参考，不能直接复刻）
- 禁止输入：参考小说原文

### 6.3 Continuity Audit

读取 `setting_rules`、`worldbuilding_pattern` 检查生成章节是否与参考方向一致（而非检查是否与参考小说一致）。

### 6.4 Originality Checker

读取 `originality_rules` 执行校验规则：

- 每次生成 Story Bible 或章节后运行
- 对照 `originality_rules` 逐条检查
- `severity: critical` → 阻止生成
- `severity: high` → 标记高风险，转入人工确认
- `severity: medium` → 标记警告

### 6.5 Prompt Builder

读取 Reference Creation Profile 的抽象字段构建 AI prompt 的"写作方向"部分，而非直接喂入参考小说原文。
