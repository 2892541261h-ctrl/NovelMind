# 剧情不换皮检查规则

> 版本：0.1.0
> 状态：草案（尚未实现）
> 关联任务：T069

---

## 1. 功能定位

Plot Reskin Guard（剧情不换皮检查器）专门检查 AI 生成的 Story Bible 或小说章节中的剧情结构是否是对参考小说剧情的变相复刻。

**核心原则：允许借鉴抽象的冲突模式和章节推进方式，禁止复制任何具体的剧情桥段链条。**

---

## 2. 检查范围

Plot Reskin Guard 从以下维度逐项检查：

| 维度 | 说明 |
|---|---|
| 关键桥段 | 剧情中的标志性事件节点 |
| 转折点 | 剧情方向的重大转变 |
| 冲突结构 | 冲突的类型、规模和升级模式 |
| 章节钩子 | 每章结尾的悬念或情感钩子 |
| 结局走向 | 最终冲突的解决方式和结局形态 |
| 剧情链条 | 事件之间的因果推进序列 |

---

## 3. 关键桥段检查

### 3.1 什么是关键桥段

关键桥段是剧情中具有以下特征的事件节点：
- 角色命运发生重大变化
- 世界观认知发生根本转变
- 人物关系发生质变
- 主线剧情进入新阶段

### 3.2 检查方法

将关键桥段抽象为"事件类型 + 触发条件 + 结果类型"三元组：

```
参考小说桥段：                 待检查桥段：
┌──────────────────┐         ┌──────────────────┐
│ 事件：门派被灭     │         │ 事件：师门被毁     │
│ 触发：内部叛徒泄密  │         │ 触发：内奸出卖      │
│ 结果：主角踏上复仇路│         │ 结果：主角开始复仇   │
└──────────────────┘         └──────────────────┘
```

### 3.3 判定规则

| 条件 | 结果 | 严重程度 |
|---|---|---|
| 关键桥段的三元组完全一致（仅替换了名词） | FAIL | critical |
| 三元组中有两个一致，一个仅名词替换 | FAIL | high |
| 三元组中有一个一致，其余不同 | WARN | medium |
| 关键桥段类型完全不同 | PASS | - |

---

## 4. 转折点检查

### 4.1 转折点类型

| 类型 | 说明 |
|---|---|
| 认知转折 | 角色对世界/对他人的认知发生根本变化 |
| 立场转折 | 角色从一方倒向另一方 |
| 能力转折 | 角色获得/失去关键能力 |
| 关系转折 | 重要关系破裂/重建 |
| 身份转折 | 角色真实身份或使命被揭示 |

### 4.2 检查方法

提取剧情中所有转折点，按类型排列为序列，与参考小说的转折点序列对比。

```
参考小说转折序列：             待检查转折序列：
[认知转折] → [关系转折]        [认知转折] → [关系转折]
     ↓                              ↓
[能力转折] → [身份转折]        [能力转折] → [身份转折]
     ↓                              ↓
[立场转折]                     [立场转折]
```

### 4.3 判定规则

| 条件 | 结果 | 严重程度 |
|---|---|---|
| 转折点类型序列完全一致（长度 ≥ 3） | FAIL | high |
| 转折点类型序列 70% 以上一致（长度 ≥ 3） | FAIL | high |
| 转折点类型序列 50-70% 一致 | WARN | medium |
| 转折点类型序列差异明显 | PASS | - |

---

## 5. 冲突结构检查

### 5.1 冲突结构维度

| 维度 | 说明 |
|---|---|
| 冲突类型 | 人物 vs 自我 / 人物 vs 人物 / 人物 vs 社会 / 人物 vs 自然 |
| 冲突规模 | 个人级 / 团队级 / 组织级 / 世界级 |
| 升级模式 | 线性升级 / 波浪式升级 / 跳跃式升级 |
| 解决方式 | 对抗解决 / 和解解决 / 妥协解决 / 回避解决 / 外部介入解决 |

### 5.2 判定规则

| 条件 | 结果 | 严重程度 |
|---|---|---|
| 四个维度与参考小说完全一致 | FAIL | high |
| 三个维度与参考小说一致 | WARN | medium |
| 两个或以下维度一致 | PASS | - |

---

## 6. 章节钩子检查

### 6.1 钩子类型

| 类型 | 说明 |
|---|---|
| 悬念钩子 | 章尾揭示一个未解之谜 |
| 危机钩子 | 章尾引入新的危险或冲突 |
| 关系钩子 | 章尾暗示人物关系即将变化 |
| 情感钩子 | 章尾以强烈的情感余韵收尾 |
| 信息钩子 | 章尾提供关键信息但留有余地 |

### 6.2 检查方法

提取章节（章尾）的连续钩子类型序列，与参考小说的钩子节奏对比。

### 6.3 判定规则

| 条件 | 结果 | 严重程度 |
|---|---|---|
| 连续 5 章以上的钩子类型序列与参考小说一致 | FAIL | high |
| 连续 3-4 章的钩子类型序列与参考小说一致 | WARN | medium |
| 钩子节奏明显不同 | PASS | - |

---

## 7. 结局走向检查

### 7.1 结局维度

| 维度 | 说明 |
|---|---|
| 最终对抗形式 | 一对一决斗 / 群体对抗 / 智斗 / 无直接对抗 |
| 最终结果 | 全胜 / 惨胜 / 失败 / 牺牲 / 开放结局 |
| 主要角色归宿 | 存活/死亡/离去/转变的数量和分布 |
| 世界观最终状态 | 恢复原状 / 永久改变 / 被摧毁 / 新平衡 |

### 7.2 判定规则

| 条件 | 结果 | 严重程度 |
|---|---|---|
| 四个维度与参考小说完全一致 | FAIL | high |
| 三个维度与参考小说一致 | WARN | medium |
| 两个或以下维度一致 | PASS | - |

---

## 8. 允许借鉴的剧情模式

| 允许借鉴 | 说明 |
|---|---|
| 抽象冲突模式 | "人物 vs 自我"、"人物 vs 社会期望" 等类型 |
| 剧情推进模型 | "人物驱动"、"日常推进型"、"多线交织" 等 |
| 章节结构规律 | "以场景描写开章"、"以情感余韵收尾" 等 |
| 叙事节奏模式 | "慢热型"、"张弛交替" 等 |
| 读者钩子策略 | "人物共情型钩子"、"关系期待型钩子" 等 |
| 通用的故事阶段 | "启程-试炼-回归"、"建立-冲突-解决" 等经典三幕结构 |
| 流派惯例 | 悬疑小说的"红鲱鱼"、武侠小说的"武功升级" 等 |

---

## 9. 禁止搬运的完整剧情链条

| 禁止搬运 | 示例（均为虚构） |
|---|---|
| 完整桥段序列 | "主角被学院录取 → 结识两个好友 → 三人组解决年度危机 → 发现幕后黑手是老师 → 最终决战" |
| 具体转折点链条 | "第 1 卷能力觉醒 → 第 2 卷失去导师 → 第 3 卷叛徒揭示 → 第 4 卷终极对决" |
| 具名事件序列 | "宗门大比 → 外部入侵 → 寻找神器 → 联合抗敌 → 牺牲封神" |
| 因果关系链条 | "因为家族被灭 → 所以踏上复仇路 → 途中发现真凶另有其人 → 最终选择宽恕" |
| 换皮剧情 | 只把"魔法学校"换成"修仙学院"，把"咒语"换成"功法"，其余剧情结构完全不变 |

---

## 10. 风险等级汇总

| 检查维度 | 最高严重程度 | 判定关键 |
|---|---|---|
| 关键桥段 | critical | 事件-触发-结果三元组一致（仅名词替换） |
| 转折点序列 | high | 序列长度 ≥ 3 且 70% 以上一致 |
| 冲突结构 | high | 四个维度完全一致 |
| 章节钩子节奏 | high | 连续 5 章以上钩子类型序列一致 |
| 结局走向 | high | 四个维度完全一致 |
| 综合换皮评分 | critical | 多维度综合评分 > 0.7 |

---

## 11. 综合换皮评分公式

```
换皮评分 = Σ(维度权重 × 维度相似度)

维度权重：
- 关键桥段：0.25
- 转折点序列：0.20
- 冲突结构：0.20
- 章节钩子：0.15
- 结局走向：0.20
```

| 评分区间 | 结果 | 动作 |
|---|---|---|
| > 0.7 | FAIL（critical） | 阻止生成，要求重新设计剧情 |
| 0.4 - 0.7 | FAIL（high） | 阻止生成，转入人工确认 |
| 0.2 - 0.4 | WARN（medium） | 标记警告，建议人工审查 |
| < 0.2 | PASS | 允许继续 |

## 12. 修改建议输出格式

当检查 FAIL 或 WARN 时，输出具体的修改建议：

```json
{
  "check_id": "PLOT-001",
  "violation_type": "关键桥段换皮",
  "severity": "critical",
  "detail": "原创剧情的3个关键桥段与参考小说高度一致，仅替换了名词",
  "matched_bridges": [
    {
      "reference": "门派被灭 → 内部叛徒 → 复仇",
      "generated": "师门被毁 → 内奸出卖 → 报仇",
      "similarity": 0.92
    }
  ],
  "overall_reskin_score": 0.78,
  "suggestions": [
    "建议修改第1个关键桥段的触发条件：从'内部叛徒'改为其他类型的触发",
    "建议调整第2个关键桥段的事件类型：避免'寻找神器'模式",
    "建议重新设计转折点序列：当前序列与参考小说相似度 80%",
    "建议将结局从'惨胜'改为'开放结局'以降低结局维度相似度"
  ]
}
```
